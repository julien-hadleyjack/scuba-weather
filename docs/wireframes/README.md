# Wireframes

Static HTML mockups of the app at 390 px with sample data. Where they and [SPEC.md](../../SPEC.md) differ in text or behaviour, the spec wins.

**View them rendered:** [index.html on htmlpreview.github.io](https://htmlpreview.github.io/?https://github.com/julien-hadleyjack/scuba-weather/blob/main/docs/wireframes/index.html). GitHub only shows the HTML source, so the links go through [htmlpreview.github.io](https://htmlpreview.github.io), which renders a file from the `main` branch. Locally, open `index.html` in a browser.
